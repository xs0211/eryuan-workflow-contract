# 01.1 Representative Prompt

```text
为妆舟生成一条“主播排期后制作短视频”的工作流草案。

输入：
- 已确认的主播排期；
- 主播资料和可用参考图；
- 商品资料和参考图；
- 目标平台、用途和交付截止时间。

输出：
- 一条可播放的 30 秒成片；
- 6 个等长镜头；
- 有脚本、分镜、每镜图片和视频、音轨检查；
- 成片需要真人最终验收。

约束：
- 不得编造价格、折扣、功效或主播真实体验；
- 付费视频提交前必须有人确认素材包；
- 付费结果未知时必须先对账，不能重复提交；
- 本轮只生成草案，不运行、不付费、不发布、不写回业务系统。
```

This prompt deliberately leaves source artifacts unbound. A correct first
generation should preserve the desired output and graph semantics while marking
the actual talent/product/schedule references as missing rather than inventing
files or values.
