# 二元AI Flow Studio 交互原型

这是 `nl-atom-workflow` 需求包的可操作前端原型，用于评审以下主路径：

```text
自然语言需求
  -> 输入/输出识别
  -> 13 个业务原子匹配
  -> 四阶段流程草案
  -> 默认节点视图 / 五段高级编辑
  -> 多端口与能力绑定
  -> 合同校验
  -> 保存不可运行草案
```

## 已实现

- 自然语言生成入口与分阶段生成反馈；
- 妆舟 01.1 的 V01-V10、H02/H05/H10 共 13 个业务原子；
- 3 个真人决定节点和 6 镜分支标识；
- 节点默认视图：输入、输出、能力和真人审核状态；
- 高级编辑：输入、检查、执行、审核、输出五段配置；
- 新增显式输入/输出端口；
- 五类可调用资源的浏览和绑定；
- 13 原子字段矩阵和搜索；
- 设计校验与平台运行门禁分开的校验报告；
- 端口两端基数、稳定身份键、全部必填输入和连接拓扑校验；
- 草案完整快照本地保存，恢复前执行深度结构校验；
- 重新生成前保留撤销快照，撤销恢复完整草案；
- 提示词或配置编辑后，旧报告和绑定哈希立即失效；
- `executionReadiness` 固定为 `not_run`；
- 1440x1000 桌面端和 390x844 手机端浏览器验收。

原型没有接入真实模型、媒体服务、付费网关、生产业务流程或 V4
持久化接口。页面中的生成、资源匹配和校验均为交互演示，不代表平台
实现或执行验收通过。

## 本地运行

```bash
python3 -m http.server 4174 --bind 127.0.0.1 \
  --directory .
```

访问 `http://127.0.0.1:4174/`。

## 浏览器验收

```bash
cd /path/to/prototype
node qa.cjs
```

使用公开地址验收：

```bash
PROTOTYPE_URL="http://175.178.205.246/eryuan-workflow-builder/" \
QA_OUT_DIR="./qa-public" \
node qa.cjs
```

验收覆盖提示词入口、生成结果、节点概览、五段编辑、端口弹窗、字段矩阵、
端口基数与稳定键反例、必填输入、H05 派生正反例、完整快照、损坏存档、
存储访问拒绝、重新生成与撤销、控制台错误和横向溢出。截图与 `audit.json`
位于 `qa/` 或 `qa-public/`；失败运行也会覆盖写入 `status=failed` 的审计文件。
