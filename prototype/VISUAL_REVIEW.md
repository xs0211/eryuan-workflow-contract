# 桌面视觉与首次使用修正

起点：`8af933726fc9f49408f5236dd5399d826681b141`。仍在 `codex/desktop-contract-v0.1`，不修改 main，不创建平行前端，不部署。

用户提供的 HTML 是布局基准，MD 是数据合同。旧版本的 Node 及 DOM 通过不能证明视觉和易用性通过，本次不沿用该结论或截图。

## 已实现的结构修改

- 去掉重顶栏、静态四步条、常驻两侧栏。画布占满视口，初始无选中节点、无配置浮层。
- 左侧四个浮动入口；底部浮动工具栏。资料选择、模板、对话、步骤配置均按需打开，可关闭回到画布。
- 新样例按四个业务阶段布局并适配视口。旧存档位置保持原样，可显式“整理布局”并撤销。
- 首屏一个主操作：确认目标→确认拆解→检查缺项→进入具体步骤补充。人工新增步骤也出现在拆解中。
- 节点先展示业务目的与处理说明，模型引用、端口、业务五段和技术细节折叠。
- 继续保留九类节点、端口锁定、自定义端口和连接、Human 门禁、模板、迁移提示、保存与报告失效。检查不是运行；目标确认不是业务批准。

## 1440×1000 人工复核表

由复核方在已授权环境运行 `desktop-qa.cjs` 生成本提交的截图和审计。不得使用旧预览或旧截图。人工结论必须另行记录人、时间、提交、两张截图哈希、通过/失败及原因。

| 核对点 | 参考要求 | 本次需要观察的证据 |
|---|---|---|
| 首屏层级 | 中央画布为主体，浮动控制 | `00-owner-reference-1440.png` 对照 `01-default-canvas.png`，无固定大侧栏 |
| 卡片与连线 | 轻量白卡、细线、类型色端点 | 名称、关系和待补项可辨识，不能为了塞下画布缩到不可读 |
| 操作起点 | 用户不需要技术人员讲解 | 不看文档能发现“确认流程目标”，而不是误点真实运行 |
| 连续操作 | 每步有明确下一动作 | `01a` 目标→拆解→问题→具体步骤；无静态假按钮 |
| 配置退出 | 编辑是临时层，不占默认画布 | `01b` 关闭后恢复全画布，数据不丢 |
| 资源和对话 | 浮动、按需展开 | `01c` 四类入口、模板和对话可找到，关闭后不遮挡画布 |
| 高级内容 | 默认只说业务语言 | `02` 模型引用/五段/端口细节默认折叠，普通信息先出现 |
| 阻断与迁移 | 保留严谨语义但有可执行提示 | `03` 问题旁能直接进入相关步骤；`06` 迁移提示与边界仍可见 |

参考 HTML 是七步会议样例，当前是十三步视频样例。节点数量与业务文字不同是必要差异，不据此改变参考的画布优先、浮动工具、轻量卡片结构。

## 独立首次操作走查

给未看说明的复核者以下目标，不告诉按钮位置：“查看视频制作计划，修改脚本要求，为脚本指定审核人，检查还缺什么并保存。”

记录其第一点击、卡住的位置、误解和是否需要讲解。允许查看高级参数，但若主路径必须借助技术说明才能继续，应判为需修改。自动点击脚本不能代替这项走查。
