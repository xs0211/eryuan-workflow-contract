# 桌面浏览器复核入口

## 状态与范围

`desktop-qa.cjs` 面向当前 `relay-ui.js`，替代旧页面的 `qa.cjs` 作为本轮复核入口，但不删除旧版脚本。当前仅完成脚本语法及安全辅助函数的 Node 测试；这不代表浏览器脚本已运行或全部交互已通过。

当前环境曾拒绝浏览器操作，因此这里没有启动浏览器、开启替代预览服务或尝试其他浏览器通道。请由具备明确浏览器使用权限的复核环境运行。设置环境变量只是确认前置条件，不能解除或绕过环境限制。

本脚本不部署、不启动服务器、不安装依赖、不读取既有浏览器档案，也不登录平台。移动端不在本轮范围。

## 复跑前提

1. 取得本次功能分支，确认提交号；`prototype/` 必须没有未提交修改。
2. 复核方已有授权的静态预览地址，且内容是该提交的 `prototype/`。不能使用生产业务服务，也不能用另一个版本的公开预览冒充。
3. 复核环境已允许使用 Playwright 和 Chromium，Playwright 至少 1.48，浏览器已安装。本脚本不自动下载或安装。
4. 使用新建的隔离上下文和合成审核人引用，不载入真实客户资料、凭据或真人审批。

在上述条件满足的环境中，从仓库根目录运行：

```sh
DESKTOP_QA_AUTHORIZED=1 PROTOTYPE_URL="$AUTHORIZED_STATIC_PREVIEW" node prototype/desktop-qa.cjs
```

`AUTHORIZED_STATIC_PREVIEW` 由复核方填写已获授权的静态页面 URL，必须以 `/` 或 `/index.html` 结尾，不能包含账号、密码、查询参数或片段。默认使用已安装的 `playwright`；已有受控安装可通过 `PLAYWRIGHT_MODULE` 指定模块。脚本不会修改系统网络、浏览器权限或远端配置。

## 十组 DOM 断言

| 编号 | 覆盖内容 |
|---|---|
| 01 | 13 张业务卡，10 ai + 3 sign，9 类添加入口，12 条端口级连线，迁移提示，真实运行禁用 |
| 02 | 编辑处理说明与模型引用，保存重载保持一致 |
| 03 | 缺审核人时检查阻断，不显示下游成功结果，仍可保存 |
| 04 | 系统端口没有删除、改类型、改必填入口 |
| 05 | 单卡模板实例化换节点 ID，系统端口 ID 不变，不复制旧连线 |
| 06 | 迁移说明可打开，不能把兼容投影说成原站部署 |
| 07 | 9 类节点逐一通过实际按钮添加，再撤销 |
| 08 | 填完三处合成审核人配置后结构检查有成功对照；不生成真人批准、不开放真实运行 |
| 09 | 清空审核人使旧检查与保存态失效；再次阻断，半成品仍可保存 |
| 10 | 新增自定义口；图片接文本口拒绝，文本连接成功；删口同步删边 |

每组执行后测量文档横向溢出并截图，视口固定为 1440×1000。画布内部滚动不计为文档横向溢出。断言失败即停止，后续用例不得冒充成功。

这十组是桌面首轮验收，不替代 A–J 全量业务合同；尚未覆盖所有参数组合、完整旧草案迁移、原站部署或平台执行。

## 请求与源码身份

- 只允许指定地址、指定目录的八个静态文件 GET；资源类型也必须匹配 HTML/CSS/JS。XHR、fetch、其他地址、其他路径、写请求与 WebSocket 均阻断并使验收失败。
- 禁止服务工作线程；静态响应不自动跟随重定向、不重试；必须为 HTTP 200 且 SHA-256 与当前检出文件一致，才交给页面执行。旧页面不能混入当前提交的截图。
- 不向真实模型、媒体、支付、发布或业务接口发送测试请求。记录来自浏览器拦截器，不取页面或模型自报。
- 只有全部用例、静态文件哈希、Console、页面错误和请求检查完成后，才记录本轮 `forwardedNonStaticRequests=0`；未完成保持 `null`。
- 该计数只证明隔离浏览器在这些操作和拦截条件下没有转发非静态请求，不证明平台后端的计费账本、调用计数或生产权限。平台仍为 `not_run`，A2 不因此解除。

拦截机制依据 [Playwright 网络说明](https://playwright.dev/docs/network)、[Route.fetch](https://playwright.dev/docs/api/class-route#route-fetch) 和 [WebSocketRoute](https://playwright.dev/docs/api/class-websocketroute)。

## 证据与失败处理

输出位于被 Git 忽略的 `prototype/qa/desktop/`：

- `audit.json`：本次提交、源文件哈希、环境、每组结果、DOM 实测、Console/页面错误、静态请求日志和未运行边界。
- 每次运行有独立截图子目录，文件名与 SHA-256 写入报告；报告只引用本次目录。
- 启动即覆盖写失败态，浏览器值初始为 `not_run`/`null`；依赖缺失、权限条件不满足、旧站哈希不符、断言失败都不能沿用上次绿色结果。
- 进程非零退出或报告未完整通过时，不交付“浏览器验收通过”。截图用于视觉人工复核，DOM 断言不代表审美验收。
- 交付前检查证据不包含凭据、无关用户信息或内部环境路径；不要上传浏览器档案。

仅复跑纯函数、VM 和验收辅助函数，不启动浏览器：

```sh
node prototype/verify.cjs
```

其中 `desktop-qa.test.cjs` 的 12 项测试只验证 URL/请求限制、响应哈希和失败态初始化，不证明十组浏览器交互成功。
